# Srivathsa H. Honyal — Intelligence Map

A local React/TypeScript portfolio built as an interactive map of research, systems, and fieldwork.

## Run

```sh
npm install
npm run dev
```

Open `http://127.0.0.1:5173/`. Run `npm run build` for a production bundle in `dist/`.

Map lines indicate shared methods and investigations, not integrations between projects.
